# Textos que el negocio tiene que definir antes del chatbot

El chatbot solo puede citar lo que Litoral Maq redacte. Sin estos textos, en cada tema de la lista deriva a WhatsApp (+54 9 379 421-5065). Completar y devolver; después se cargan en una tabla `politicas` editable desde el panel y se publican también en el sitio.

| # | Tema | Qué hay que decidir | Respuesta |
| --- | --- | --- | --- |
| 1 | Horarios de atención | Días y horas del local y de WhatsApp. Qué decir fuera de horario | |
| 2 | Envíos | Zonas, transportista por zona (Vía Cargo, OCA, Andreani, Enviopack), plazos, quién paga, productos pesados | |
| 3 | Costo de envío | Hoy "a cotizar": ¿cotiza una persona o el sistema? ¿Qué datos pide (código postal, productos)? | |
| 4 | Retiro en local | Sáenz 1587: horarios, cuánto tarda en estar listo, quién puede retirar (DNI, poder) | |
| 5 | Cambios y devoluciones | Plazo, estado del producto, quién paga el flete | |
| 6 | Garantía | Plazo, quién la da (fábrica o local), qué cubre y qué no, qué datos se piden | |
| 7 | Botón de arrepentimiento | Procedimiento y plazo legal (10 días). Confirmar con contador o abogado | |
| 8 | Medios de pago y cuotas | Mercado Pago: cuotas sin interés, tarjetas, transferencia, efectivo en local | |
| 9 | Facturación | Factura A y B, qué datos hacen falta, cuándo se envía | |
| 10 | IVA en precios | Los precios publicados, ¿incluyen IVA? | |
| 11 | Compras por cantidad | Hoy tope de 3 unidades por producto. A partir de cuántas se cotiza, ¿hay precio mayorista o para empresas? | |
| 12 | Descuento de bienvenida | Confirmar condiciones: 5 % en la primera compra pagada, solo productos, sin envío | |
| 13 | Pedidos vencidos | Cuánto tiempo se reserva un pedido sin pagar antes de cancelarse | |
| 14 | Derivación | ¿Quién atiende los mensajes derivados? ¿Mismo número de WhatsApp? | |
| 15 | Qué nunca debe decir el asistente | Temas prohibidos, descuentos que no puede prometer | |
| 16 | Nombre y tono | Nombre del asistente, trato de voseo o "usted" | |

Notas:
- Los temas 5, 6, 7 y 9 tienen implicancia legal (Ley 24.240 y 25.326). Conviene que los revise el contador.
- Los puntos 3 y 13 se pueden contrastar con el código (`docs/superpowers/plans/2026-09-23-recontacto-whatsapp-pedidos-vencidos.md`); confirmar que lo implementado es lo que el negocio quiere decir.
